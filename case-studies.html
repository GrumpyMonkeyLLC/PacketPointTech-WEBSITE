City of Wadsworth: Brocade ICX to Arista Campus Switch Migration

The City of Wadsworth needed to replace an aging Brocade ICX access layer that had grown difficult to manage, support, and secure. The project involved a full access layer overhaul across multiple municipal sites — migrating to a modern Arista campus switching platform at scale, with complete documentation and zero unplanned downtime to city services throughout the transition.

Bradley's Saving Grace: Full-Stack Azure Web Presence

Bradley's Saving Grace needed a professional web presence to support their mission and drive donor engagement — without the overhead of paid hosting eating into their operating budget. We designed and built a full-stack website on Azure Static Web Apps with an Azure Functions v4 backend, Table Storage for data persistence, Blob Storage for media, and a complete GitHub Actions CI/CD pipeline. The result is a fast, modern, fully managed site that costs the organization nothing to host, with automatic deployments from every code push.
