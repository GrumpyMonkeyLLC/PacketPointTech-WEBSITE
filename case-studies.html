Replacing a city’s switches without interrupting city services

1The problem

The city’s access switches, an aging Ruckus ICX line, were getting hard to manage, support, and secure. They connect city offices, and a bad cutover would be felt by residents, not just staff.

2What we did

  • Planned the move to Arista campus switching site by site, with changes done in scheduled windows.
  • Set up NetBox so every switch, port, and address is documented in one place.
  • Added Prometheus monitoring so problems show up on a dashboard before someone calls about them.
  • Provide ongoing software and network support for the city.

3The result

The migration is moving forward without disrupting city services, and the city’s staff have current documentation and monitoring for the network as it changes.

A nonprofit website that costs nothing to run

1The problem

Bradley’s Saving Grace needed a proper website to share its mission and bring in donors. Every dollar spent on hosting would have come straight out of its operating budget.

2What we did

  • Designed and built a custom site on Azure Static Web Apps’ free tier.
  • Added an Azure Functions backend, with Table Storage for data and Blob Storage for photos.
  • Set up automatic publishing, so every update goes live without anyone logging into a server.

3The result

A fast, modern website that supports the organization’s mission, with no hosting bill and no servers to look after. We did the work pro bono.
