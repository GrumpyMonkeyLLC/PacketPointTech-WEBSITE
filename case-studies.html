Moving the City of Wadsworth from Brocade to Arista

The city’s Brocade ICX access switches had reached the point where they were hard to manage, hard to get support for, and hard to keep secure. The job was to replace the whole access layer across multiple municipal sites with Arista campus switching while city services kept running.

We moved VLANs and spanning tree over in planned change windows, used Ansible to keep switch configs consistent, and recorded every device, port, and address in NetBox as we went. When the work was done, the city’s IT staff had current documentation for the whole access layer.

A website for Bradley’s Saving Grace that costs nothing to run

Bradley’s Saving Grace needed a proper website to support its mission and bring in donors, but paying for hosting would have come straight out of its operating budget.

We designed and built the site on Azure Static Web Apps, with an Azure Functions backend, Table Storage for data, and Blob Storage for photos and media. A GitHub Actions pipeline publishes every change automatically, so updates go live without anyone logging into a server.
