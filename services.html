Networking

We design, install, and manage wired and wireless networks, from a single office to multi-site setups with redundant links. Everything we touch gets labeled, diagrammed, and entered into NetBox.

Cisco IOSMerakiArista EOSRuckus FastIronJuniper JunosUniFi
  • Network design for single and multi-site environments
  • Switching and routing on Cisco, Arista, and Ruckus
  • OSPF, BGP, and EIGRP configuration and cleanup
  • Wi-Fi coverage planning and a separate, locked-down guest network
  • VLAN segmentation to keep cameras, phones, guests, and staff apart
  • QoS for VoIP and video calls
  • NetBox documentation: IP addressing, rack diagrams, inventory
  • Monitoring and alerting from day one

Security & compliance

Layered security that covers the firewall, the endpoints, the accounts, and the people using them. If you handle card payments or health records, we design with PCI DSS or HIPAA in mind from the start instead of patching things up before an audit.

Palo AltoSophosEDRMFA
  • Firewall deployment on Palo Alto and Sophos
  • PCI DSS and HIPAA consulting, implementation, and audit prep
  • Security awareness training for staff
  • Password manager and MFA rollouts
  • Vulnerability scans and a plan to fix what they find
  • Incident response plans and tabletop exercises
  • Written security policies
  • Endpoint detection and response (EDR)

Automation

Configuration written as code and kept in version control. Every change is tracked, can be reviewed before it goes out, and can be rolled back if it causes trouble.

AnsiblePythonTerraformGitHub Actions
  • Ansible playbooks for configuration and deployment
  • Infrastructure as code with full change history
  • Python scripts for repetitive tasks and system integrations
  • Pipelines that test and apply infrastructure changes

  • Drift detection, so manual changes don’t pile up unnoticed
